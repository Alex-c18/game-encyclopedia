# 🎮 Game Encyclopedia (Игровая энциклопедия)

Интерактивное веб-приложение, представляющее собой энциклопедию видеоигр. Проект позволяет пользователям находить игры, изучать их характеристики, добавлять понравившиеся в личные закладки и делиться мнением в комментариях.

Разработка выполняется в рамках лабораторных работ и курсового проекта по дисциплине «Технологии разработки веб-приложений».

---

## ✨ Основные возможности

### 👤 Гостевой пользователь
* Просмотр каталога игр с фильтрацией (по жанрам, году выпуска, платформам) и сортировкой.
* Поиск игр по названию.
* Просмотр детальной карточки игры (описание, системные требования, медиагалерея, внешние ссылки на Steam/официальный сайт).
* Просмотр отзывов и комментариев пользователей.
* Регистрация и аутентификация в системе.

### 🔐 Авторизованный пользователь
* Добавление и удаление игр из личного списка («Закладки»).
* Публикация комментариев на страницах игр.
* Управление персональным профилем.

### 🛡️ Администратор
* Управление каталогом (добавление, редактирование, удаление игр).
* Модерация пользовательских комментариев.

---

## 🛠 Технологический стек

* **Frontend:** React, TypeScript, Vite, Material UI (MUI)
* **Backend:** C# / ASP.NET Core Web API
* **ORM:** Entity Framework Core
* **Database:** PostgreSQL
* **DevOps / Tools:** Docker, Git
