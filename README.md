# 🎮 Game Encyclopedia (Игровая энциклопедия)

Интерактивное веб-приложение, представляющее собой энциклопедию видеоигр. Проект позволяет пользователям находить игры, изучать их характеристики, добавлять понравившиеся в личные закладки и делиться мнением в комментариях.

---

## ✨ Основные возможности

* **Каталог и поиск:**
  * Поиск игр по названию.
  * Гибкая фильтрация и сортировка по годам выхода, жанрам и платформам.
* **Карточка игры:**
  * Подробное описание и основные свойства.
  * Медиагалерея (скриншоты, видео-трейлеры).
  * Минимальные и рекомендуемые системные требования.
  * Внешние ссылки на Steam и официальные сайты издателей.
* **Интерактив и личный кабинет:**
  * Добавление игр в личные «Закладки» (для авторизованных пользователей).
  * Возможность оставлять комментарии и отзывы под карточками игр.

---

## 🛠 Технологический стек

* **Backend:** PHP
* **Frontend:** HTML5, CSS3, JavaScript, jQuery
* **Database:** PostgreSQL
* **DevOps / Tools:** Docker (под вопросом), Git (GitHub)
